## Type Definitions

All type definitions are exported from `src/types/index.ts`.

### Type: Direction

```typescript
type Direction = 'up' | 'down' | 'left' | 'right';
```

**Description**: Represents the four possible movement directions for tiles on the board.

**Valid Values**:
- `'up'` - Move tiles upward
- `'down'` - Move tiles downward
- `'left'` - Move tiles leftward
- `'right'` - Move tiles rightward

**Used By**: `move()`, `handleMove()`, keyboard event handler

---

### Interface: Tile

```typescript
interface Tile {
  id: number;
  value: number;
  row: number;
  col: number;
  mergedFrom?: [Tile, Tile];
}
```

**Description**: Represents a single tile on the game board.

**Properties**:

#### id
- **Type**: `number`
- **Description**: Unique identifier for the tile, auto-incremented from 1
- **Generated By**: Internal `makeId()` function in gameLogic.ts

#### value
- **Type**: `number`
- **Description**: The numeric value displayed on the tile
- **Valid Values**: Powers of 2 from 2 to 2048+ (2, 4, 8, 16, 32, 64, 128, 256, 512, 1024, 2048, 4096, 8192, etc.)
- **Initial Values**: 2 (90% probability) or 4 (10% probability)

#### row
- **Type**: `number`
- **Description**: Zero-based row position on the board
- **Range**: 0-3

#### col
- **Type**: `number`
- **Description**: Zero-based column position on the board
- **Range**: 0-3

#### mergedFrom
- **Type**: `[Tile, Tile] | undefined`
- **Description**: Optional tuple of the two tiles that merged to create this tile
- **Usage**: Used for animation and tracking merge history
- **Default**: `undefined` (not merged)

**Example**:
```typescript
const tile: Tile = {
  id: 1,
  value: 2,
  row: 0,
  col: 0
};

const mergedTile: Tile = {
  id: 3,
  value: 4,
  row: 1,
  col: 2,
  mergedFrom: [tile1, tile2]
};
```

### Type: Board

```typescript
type Board = (Tile | null)[][];
```

**Description**: Represents the 4x4 game board as a 2D array.

**Structure**: 4x4 matrix where each cell is either:
- `Tile` - A tile object occupying that position
- `null` - An empty cell

**Dimensions**: Always 4 rows × 4 columns

**Example**:
```typescript
const board: Board = [
  [{ id: 1, value: 2, row: 0, col: 0 }, null, null, null],
  [null, { id: 2, value: 4, row: 1, col: 1 }, null, null],
  [null, null, null, null],
  [null, null, null, null]
];
```

### Interface: GameState

```typescript
interface GameState {
  board: Board;
  score: number;
  bestScore: number;
  won: boolean;
  over: boolean;
  keepPlaying: boolean;
}
```

**Description**: Complete state of the game at any point in time.

**Properties**:

#### board
- **Type**: `Board`
- **Description**: Current 4x4 game board with all tiles

#### score
- **Type**: `number`
- **Description**: Current game session score
- **Range**: 0 to unlimited
- **Calculation**: Sum of all merged tile values (e.g., merging two 2s adds 4 points)

#### bestScore
- **Type**: `number`
- **Description**: All-time highest score across all sessions
- **Persistence**: Stored in localStorage at key `'2048-best-score'`
- **Default**: 0

#### won
- **Type**: `boolean`
- **Description**: Whether the player has achieved a 2048 tile
- **Trigger**: Set to `true` when `hasWon(board)` returns true
- **Behavior**: Once true, remains true for the game session

#### over
- **Type**: `boolean`
- **Description**: Whether the game is over (no valid moves remaining)
- **Trigger**: Set to `true` when `isGameOver(board)` returns true
- **Blocks**: Further moves when true

#### keepPlaying
- **Type**: `boolean`
- **Description**: Whether player chose to continue after winning
- **Default**: `false`
- **Usage**: Allows moves to continue after winning if set to `true`

**Example**:
```typescript
const gameState: GameState = {
  board: initBoard(),
  score: 128,
  bestScore: 512,
  won: false,
  over: false,
  keepPlaying: false
};
```

### Function: addRandomTile()

```typescript
addRandomTile(board: Board): Board
```

**Purpose**: Adds a new tile with value 2 (90%) or 4 (10%) to a random empty cell.

**Parameters**:
- `board` (Board): Current game board

**Returns**: `Board` - New board with added tile, or unchanged board if no empty cells

**Behavior**:
1. Scans board for all empty cells
2. If no empty cells, returns original board unchanged
3. Selects random empty cell
4. Places new tile with value 2 (90% probability) or 4 (10% probability)
5. Assigns unique ID and coordinates to tile

**Side Effects**: Increments internal tile ID counter

**Example**:
```typescript
const board = emptyBoard();
const withTile = addRandomTile(board);
// Board now has one tile (value 2 or 4) at random position

const fullBoard = /* board with no empty cells */;
const unchanged = addRandomTile(fullBoard);
// Returns same board reference if full
```

initBoard(): Board

**Parameters**: None

### Function: move()

```typescript
move(
  board: Board,
  direction: Direction
): { board: Board; score: number; moved: boolean }
```

**Purpose**: Executes a tile movement in the specified direction, merging tiles and calculating score.

**Parameters**:
- `board` (Board): Current game board
- `direction` (Direction): Direction to move ('up', 'down', 'left', 'right')

**Returns**: Object with:
- `board` (Board): New board state after move
- `score` (number): Points earned from merges in this move
- `moved` (boolean): Whether any tile position changed

**Algorithm**:
1. Transform board to reduce all directions to left-slide operation:
   - Vertical moves: transpose board
   - Right/down moves: flip horizontally
2. Apply `slideRow()` to each row:
   - Compact non-null tiles to the left
   - Merge adjacent tiles with same value
   - Create new tile with doubled value
   - Calculate score from merges
3. Reverse transformations to restore orientation
4. Update all tile coordinates to match final positions

**Merge Rules**:
- Only adjacent tiles with same value merge
- Each tile merges at most once per move
- Merged tile has value = sum of merged tiles
- Score increases by merged tile value

**Side Effects**: Increments internal tile ID counter for merged tiles

**Example**:
```typescript
const board: Board = [
  [{ id: 1, value: 2, row: 0, col: 0 }, { id: 2, value: 2, row: 0, col: 1 }, null, null],
  [null, null, null, null],
  [null, null, null, null],
  [null, null, null, null]
];

const result = move(board, 'left');
// result.board: tile at [0,0] with value 4
// result.score: 4
// result.moved: true

const noMove = move(board, 'left');
// If board already compressed left:
// noMove.moved: false
// noMove.score: 0
```

### Function: hasWon()

```

**Returns**: `boolean` - `true` if any tile has value 2048, otherwise `false`

**Side Effects**: None (pure function)

  // Player reached 2048!
}
```

---

### Function: isGameOver()

```typescript
isGameOver(board: Board): boolean
```

**Purpose**: Determines if the game is over (no valid moves remain).

**Parameters**:
- `board` (Board): Current game board

**Returns**: `boolean` - `true` if game is over, otherwise `false`

**Algorithm**:
1. Check for any empty cells - if found, return `false` (can add tile)
2. For each tile, check adjacent tiles (right and down only to avoid duplicates)
3. If any adjacent tiles have same value, return `false` (can merge)
4. If no empty cells and no mergeable pairs, return `true`

**Side Effects**: None (pure function)

**Example**:
```typescript
const gameOver = isGameOver(board);
if (gameOver) {
  // No moves left, game ends
}
```

### Function: initGameState()

```typescript
initGameState(bestScore?: number): GameState
```

**Purpose**: Creates initial game state for a new game.

**Parameters**:

**Returns**: `GameState` - Fresh game state with new board and reset scores

**State Values**:
- `board`: New board from `initBoard()`
- `score`: 0
- `bestScore`: Provided value or 0
- `won`: false
- `over`: false
- `keepPlaying`: false

**Side Effects**: Calls `initBoard()`, which increments tile ID counter

**Example**:
```typescript

// Fresh game with bestScore = 0

// Fresh game preserving best score of 1024
```

### Function: loadLeaderboard()

```typescript
loadLeaderboard(): LeaderboardEntry[]
```

**Purpose**: Loads leaderboard entries from localStorage.

**Parameters**: None

**Returns**: `LeaderboardEntry[]` - Array of leaderboard entries sorted by score descending, or empty array

**Behavior**:
1. Reads from localStorage key `'2048-leaderboard'`
2. Parses JSON data
3. Returns parsed array or `[]` on any error

- localStorage is unavailable
- Key doesn't exist
- JSON parsing fails
- Data is malformed

**Side Effects**: None (read-only)

// Returns: [{ score: 4096, date: "10/3/2026" }, ...]
// Or: [] if no data

---

### Function: saveToLeaderboard()

```typescript
saveToLeaderboard(score: number): void
```

**Purpose**: Adds a new score to the leaderboard and persists to localStorage.

**Parameters**:
- `score` (number): Final game score to save

**Returns**: `void`

**Behavior**:
1. Loads existing leaderboard entries
2. Appends new entry with current date from `new Date().toLocaleDateString()`
3. Sorts all entries by score descending
4. Keeps only top 10 entries
5. Saves to localStorage as JSON

**Error Handling**: Silently fails if localStorage is unavailable

**Side Effects**: Writes to localStorage at key `'2048-leaderboard'`

**Example**:
```typescript
saveToLeaderboard(2048);
// Adds entry: { score: 2048, date: "10/3/2026" }
// Updates localStorage with sorted, trimmed list
```

## Custom Hooks

All hooks are exported from `src/hooks/useGame.ts`.

### Hook: useGame()

```typescript
useGame(): {
  state: GameState;
  newGame: () => void;
  keepPlaying: () => void;
  handleMove: (direction: Direction) => void;
}
```

**Purpose**: Manages complete game state, keyboard input, and best score persistence.

**Parameters**: None

**Returns**: Object with:

#### state
- **Type**: `GameState`
- **Description**: Current game state including board, scores, and flags

#### newGame
- **Type**: `() => void`
- **Description**: Starts a new game, preserving best score

#### keepPlaying
- **Type**: `() => void`
- **Description**: Continues playing after winning (reaching 2048)

#### handleMove
- **Type**: `(direction: Direction) => void`
- **Description**: Executes a move in the specified direction

**State Management**:
- **Initial State**: Calls `initGameState(loadBest())` to load saved best score
- **Persistence**: Automatically saves best score to localStorage on each move

**Keyboard Handling**:
- **Listens To**: `keydown` events on `window`
- **Mapped Keys**:
  - `ArrowUp` → `'up'`
  - `ArrowDown` → `'down'`
  - `ArrowLeft` → `'left'`
  - `ArrowRight` → `'right'`
- **Behavior**: Calls `preventDefault()` to prevent page scrolling
- **Cleanup**: Removes event listener on unmount

**Side Effects**:
- Reads from localStorage at key `'2048-best-score'` on mount
- Writes to localStorage at key `'2048-best-score'` on each move
- Calls `saveToLeaderboard()` when game ends

**Example**:
```typescript
const GameComponent = () => {
  const { state, newGame, keepPlaying, handleMove } = useGame();

  return (
    <div>
      <p>Score: {state.score}</p>
      <p>Best: {state.bestScore}</p>
      {state.won && !state.keepPlaying && (
        <button onClick={keepPlaying}>Keep Playing</button>
      )}
      <button onClick={newGame}>New Game</button>
      <Board board={state.board} />
    </div>
  );
};
```

## Game Mechanics Summary

### Initialization
1. Create 4×4 board with all null cells
2. Add 2 random tiles (value 2 or 4)
3. Load best score from localStorage

### Move Execution
1. User presses arrow key or calls `handleMove()`
2. Transform board based on direction
3. Slide and merge tiles in transformed orientation
4. Calculate score from merges
5. Reverse transformation to restore orientation
6. Add new random tile if board changed
7. Update current and best scores
8. Check win condition (2048 tile)
9. Check game over condition (no moves)
10. Save to leaderboard if game over

### Merge Rules
- Tiles slide in movement direction until blocked
- Adjacent tiles with same value merge into one
- Merged tile value = sum of merged tiles
- Score increases by merged tile value
- Each tile merges maximum once per move

### Win/Lose Conditions
- **Win**: Any tile reaches 2048
- **Lose**: No empty cells AND no adjacent tiles with same value
- **Continue**: Player can keep playing after winning

### Score Calculation
- Score increases by value of each merged tile
- Example: Merging two 2s adds 4 points
- Example: Merging two 1024s adds 2048 points
- Best score persists across sessions

## Error Handling

### localStorage Errors
All localStorage operations are wrapped in try-catch blocks and fail silently:

- **Best Score Load**: Returns `0` if unavailable
- **Best Score Save**: No-op if unavailable
- **Leaderboard Load**: Returns `[]` if unavailable
- **Leaderboard Save**: No-op if unavailable

### Keyboard Event Handling
- Only arrow keys trigger moves
- `preventDefault()` prevents page scrolling
- Non-arrow keys are ignored

### Board Edge Cases
- **Full Board**: `addRandomTile()` returns unchanged board
- **No Valid Moves**: `move()` returns `moved: false`, no tile added
- **Win After Win**: First win sets `won: true`, subsequent 2048s ignored
- **Move When Over**: Hook blocks moves if `state.over === true`
- **Move When Won**: Hook blocks moves if `state.won === true && !state.keepPlaying`
